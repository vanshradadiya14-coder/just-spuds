# New-order alert sound

Drop the store's alarm sound in this folder as **`new-order.mp3`** (or `new-order.wav` / `new-order.ogg`).

Every staff screen (Kitchen Display, Counter Till, Admin Console) plays it on repeat when a customer places a web order, until someone accepts, declines or silences the order. If no file is here the built-in two-tone siren plays instead.

- Keep it short (1–4 seconds) — it repeats with a small gap until the order is dealt with.
- A manager can also upload a per-device sound from **KDS → 🔔 ⚙️** or **Till → ⚙️ Settings → New order alert sound**.
- Volume and the on/off switch live in the same settings screen.
